4. Biểu tượng trạng thái trên File Explorer sẽ hiển thị gì?
* File Explorer sẽ hiển thị biểu tượng Hai mũi tên xoay tròn màu xanh dương 
* Nếu quá trình bị gián đoạn khi gập máy đột ngột, nó có thể chuyển sang biểu tượng Dấu chấm than màu đỏ


* File chỉ thực sự an toàn trên Cloud khi hiển thị Dấu tích xanh lá 




* Hệ thống xử lý thế nào khi gập máy ngay:
* Tiến trình tải lên bị ngắt kết nối Internet đột ngột giữa chừng. Dữ liệu mới sửa vẫn nằm trên ổ cứng máy đó, nhưng trên Cloud vẫn chỉ lưu phiên bản cũ.


* Việc thành viên cần làm trước khi tắt máy/gập máy:
* Quan sát icon trạng thái của file/folder: Đảm bảo file vừa sửa đã chuyển sang icon tích xanh thay vì đang xoay tròn.
